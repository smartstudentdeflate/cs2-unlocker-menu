## 🧩 About

**Counter-Strike 2 Companion** is a curated list of Counter-Strike 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, overlay overlay, round tracker
- **Quality-of-Life Helpers** — loadout catalog, buy bind manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Practice Helpers
- Round Tracker — review round flow from any checkpoint
- overlay Overlay — visualize map layout and team positions
- Replay Notes — record and review match runs
- Playback Speed — adjust demo playback for study (0.1x to 5x)

### 🎨 Loadout & Cosmetics
- Loadout Catalog — browse weapons, skins, stickers, gloves
- Custom Config Notes — organize player settings
- Buy Bind Manager — improved buy-menu visibility

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any map
- Nade Lineup Notes — chain utility lineups in the editor
- Movement Buffer Notes — review movement maneuvers in practice
